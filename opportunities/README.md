# Opportunity tracking

The generated GSC report finds candidates. This ledger records decisions and outcomes.

Add an opportunity only after checking the query's search results, intent, existing site URLs and commercial fit. Give it a stable ID such as `OPP-2026-001`. Record the exact evidence period and baseline before changing the site.

Use the states in `.docs/operating-loop.md`. At day 28 and day 90, record the same metric on a comparable date range. Set the outcome to `won`, `lost`, `inconclusive` or `superseded`, with the reason in notes.
