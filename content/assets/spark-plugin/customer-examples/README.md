# Spark Plugin customer examples

Article-ready screenshots of visible Spark Plugin treatments found on Multilingualizer customer websites.

- `clean/` contains unaltered webpage pixels in wide and close-up crops.
- `annotated/` adds a factual header and orange outline without changing the captured page.
- `manifest.json` records the source URL, feature, language, framing and alt text.

Raw 1280×720 captures stay in the ignored `data/customer-intelligence/saas-screenshot-audit/raw/spark/` directory.

Regenerate these files with `npm run clients:prepare-saas-assets`. Recheck the live page and current Spark installation before publication.
