# HubSpot customer examples

Article-ready screenshots of a visible HubSpot lead form on a multilingual customer website.

The captured English form has a distinct live Dutch counterpart using labels including `Land`, `Waarom ben je geïnteresseerd?` and `Blijf op de hoogte`. The Dutch DOM was verified on 21 August 2026, but the browser capture service refused a further bitmap after the English capture, so no Dutch image is represented here.

`clean/` contains wide and close-up pixel-faithful crops. `annotated/` adds a factual header and outline. Raw captures stay in the ignored `data/customer-intelligence/saas-screenshot-audit/raw/hubspot/` directory. Regenerate with `npm run clients:prepare-saas-assets`.
