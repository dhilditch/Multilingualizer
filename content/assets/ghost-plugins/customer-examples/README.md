# Ghost Plugins customer examples

Article-ready screenshots of a Ghost Plugins video pop-up on a customer Squarespace website.

The trigger view supplies page context. The opened wide and close-up views show the actual Ghost video lightbox. `clean/` preserves the captured pixels; `annotated/` adds only a header and outline.

Raw captures stay in the ignored `data/customer-intelligence/saas-screenshot-audit/raw/ghost/` directory. Regenerate with `npm run clients:prepare-saas-assets` and recheck the live feature before publication.
