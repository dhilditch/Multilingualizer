Check the cause before removing a script

This video records a specific conflict involving jQuery 1.11 and 3.2.1. Those version numbers describe the recorded example, not a recommendation for a new installation. A broken image popup or language switcher doesn't, by itself, prove that duplicate jQuery is the cause.

Record the console error and identify the scripts loaded on the affected page. Check which version each component requires. Save the current code before making any change, and test a proposed change on a copy of the page or a test site first.

jQuery's official noConflict documentation explains how its global variables can conflict and cautions against loading two versions. It also describes limitations when plugins rely on those globals. Adding noConflict or deleting a script isn't a universal fix.

If your problem concerns Multilingualizer, start with the troubleshooting guide and check the language-selector configuration. After resolving it, use the Squarespace launch checklist to retest navigation, forms and the language switcher.
