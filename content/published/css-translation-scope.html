Check what CSS can and can't translate

The examples below change displayed labels using generated CSS content. They don't change the original text in the HTML, translate notification emails or grant access to protected checkout and account screens. Use the Squarespace checkout, forms and emails guide to check those separate parts of the journey.

Prefer an editable text label or the platform's language setting when one is available. CSS-generated text isn't a reliable substitute for meaningful text in the document: MDN describes accessibility limitations, including browser and assistive-technology combinations that don't announce it.

Before publishing a CSS replacement, check the visible label in each language, keyboard navigation and the control's accessible name with a screen reader. Test narrow screens too. The selectors below belong to the example template; inspect your own element rather than assuming the same selector exists.

For the wider setup, follow the Squarespace multilingual guide, then work through the multilingual launch checklist.
