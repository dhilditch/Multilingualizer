# Problem

Architecture and property sites are image-led, but visitors still need services, locations, project context and enquiry routes in the right language.

# Evidence

- Architecture and property is the third-largest classified Squarespace sector in the dataset with 32 current sites.
- Multilingualizer is publicly detectable on 19 current Squarespace sites in this sector, belonging to 17 customers.

# Existing URL decision

- Canonical URL: `/multilingual-squarespace-architecture-examples/`.
- Competing internal URLs: none.
- Link gallery-specific problems to Spark, Ghost or Elfsight tutorials only where relevant.

# Solution structure

1. Verify three to five studios or property businesses.
2. Compare project index, project detail, about and contact pages across languages.
3. Check project titles, location names, captions, filters and mobile navigation.
4. Explain how image-led pages can hide untranslated functional text.

# Product fit and CTA

- Multilingualizer for manually managed portfolio and service copy.
- Spark or Ghost only for a demonstrated gallery or layout requirement.
