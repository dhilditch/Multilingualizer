# Problem

Most Squarespace multilingual advice describes tooling but gives no evidence about the businesses, countries, sectors or language combinations that actually use it.

# Evidence

- Search Console: the connected domain property returned no query rows for the latest collected period, so this is an information-gain and digital-PR opportunity rather than a GSC-led expansion.
- Internal study: 1,202 paid customers; 337 customers with 418 currently reachable Squarespace sites; 214 customers still exposing Multilingualizer on a Squarespace site.
- Method and limitations: [.docs/customer-data-content-plan.md](../../.docs/customer-data-content-plan.md).
- Fresh crawl and classifications: `data/customer-intelligence/customer-intelligence.sqlite3`, audited 21 August 2026.
