# Problem

A Squarespace owner wants translated pages indexed and needs to understand URLs, hreflang, canonicals, metadata and validation.

# Evidence

- GSC: no query rows in the current export.
- Primary sources: Google recommends separate URLs and hreflang. Weglot documents subdomain/subdirectory SEO, canonical handling and a Squarespace-specific original-page hreflang limitation.

# Existing URL decision

- Create `/squarespace-weglot-seo/`.
- The old Multilingualizer SEO post concerns a different implementation. Do not merge it into this Weglot-specific technical guide.

# Solution structure

1. Choose and verify separate language URLs.
2. Check translated title, description, canonical, hreflang and visible language.
3. Validate original and translated versions.
4. Monitor indexation and resolve common errors.

# Product fit and CTA

- Weglot is the stronger fit where indexable per-language URLs are required.
- Multilingualizer callout must state that its same-page approach is a different SEO model.

# Success metric

Non-branded impressions, clicks to the calculator and affiliate clicks.
