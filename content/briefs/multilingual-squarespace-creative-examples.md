# Problem

Creative portfolios need the visual work to remain central while services, credits, captions and enquiries remain understandable in each language.

# Evidence

- Creative and media is the second-largest classified Squarespace sector with 41 current sites.
- Multilingualizer is publicly detectable on 26 current Squarespace sites in this sector, belonging to 23 customers.

# Existing URL decision

- Canonical URL: `/multilingual-squarespace-creative-portfolio-examples/`.
- Competing internal URLs: none.
- Route gallery layout questions to a specific Spark or Ghost tutorial.

# Solution structure

1. Verify three to five public portfolio implementations.
2. Compare work index, project detail, about and enquiry pages.
3. Check captions, credits, filters, image links and mobile language controls.
4. Separate translation problems from gallery-layout problems.

# Product fit and CTA

- Multilingualizer for editor-managed portfolio text.
- Spark or Ghost only where a specific layout limitation is demonstrated.
- Elfsight only where the portfolio genuinely needs an external social or gallery feed.
