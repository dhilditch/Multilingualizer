# Problem

Spark contains a large feature library. Buyers need help matching one visible Squarespace problem to a feature, including whether the change survives mobile and language switching.

# Evidence

- Spark was publicly detectable for four of 337 customers with a reachable Squarespace site (1.2%).
- The official feature library currently includes Number Counter, Gallery Styles, section/block visibility and cookie-banner styling: [Spark features](https://www.sparkplugin.com/features).
- Official setup model and product claims: [How Spark works](https://www.sparkplugin.com/how-it-works).

# Existing URL decision

- Canonical URL: `/spark-plugin-squarespace-review-examples/`.
- Competing internal URLs: none.
- Individual feature tutorials target separate problem queries.

# Solution structure

1. Explain how Spark is installed and edited inside Squarespace.
2. Test five features against a current Squarespace 7.1 reference site.
3. Record editor workflow, mobile behaviour, language interaction, code removal and plan requirement.
4. State who gains value from the bundle and who needs only one small code snippet.

# Product fit and CTA

- Primary CTA: Spark only where two or more tested enhancements justify the bundle.
- Link to Ghost or a free snippet when one narrow fix is enough.
- Keep Multilingualizer as the translation CTA.
