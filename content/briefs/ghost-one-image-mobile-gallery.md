# Problem

A Squarespace grid gallery can become cramped on mobile. The user wants one image per row without rebuilding the desktop gallery.

# Evidence

- Ghost Plugins was publicly detectable for three of 337 customers with a reachable Squarespace site (0.9%).
- Ghost publishes a current [one image per row mobile gallery](https://www.ghostplugins.com/freeplugins/1-image-per-row-on-mobile-grid-gallery) snippet for Squarespace 7.1 Simple and Strips gallery sections.
- The official page says it is not compatible with Masonry Layout or the Grid Gallery Block.
