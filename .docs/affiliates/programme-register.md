## Interpretation limits

- A third-party script proves use, not payment. Free tiers, trials and bundled products
  exist. A confirmed affiliate programme is evidence that the vendor has commercial
  products, not that every detected customer pays that vendor.
- Customer counts can overlap because one site can use several products.
- Language-migration counts use the dedicated multilingual detector and can differ from
  generic JavaScript fingerprint counts.
- `No public programme found` must be rechecked before publishing a claim that a vendor
  has no programme.
