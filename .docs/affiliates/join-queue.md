# Affiliate application queue

Checked: 20 August 2026

The priority combines commercial fit with Multilingualizer's audience, observed customer
usage, commission quality and the likelihood of producing honest, useful content. A high
customer count proves relevance, but does not by itself prove that a programme will
convert because existing customers are not eligible as new referrals.

  https://www.ezoic.com/blog/why-a-more-strategic-approach-was-needed-for-ezoic-affiliates
- SociableKIT's current official help article says it has no affiliate programme. An old
  2017 release announcing one is therefore not treated as current evidence:
  https://help.sociablekit.com/en-us/article/do-you-have-an-affiliate-program-a5ul0q/

## Application preparation

Before submitting the first batch:

1. Prepare one accurate description of Multilingualizer's audience and channels.
2. Link to relevant existing platform and multilingual content, not a generic homepage.
3. State that recommendations are editorially independent and alternatives are selected
   by use case.
4. Save the approval date, account email, programme/network, affiliate ID, payout method,
   allowed promotion methods and final terms in this folder. Do not save passwords,
   tokens, tax forms or customer data in Git.
5. Add disclosure and link-tracking conventions before publishing the first link.
