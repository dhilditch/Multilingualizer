## Platform-expansion rule

Add a platform only after four checks:

1. The current builder permits the code or integration Multilingualizer needs.
2. A repeatable installation has been tested on the current builder version and plan.
3. Search demand or recurring community questions exist.
4. Multilingualizer has a clear advantage for a defined user, not merely a generic claim that it works everywhere.
